03Approach

Why these cases

Food science and economics let me read a business from both sides: the science that creates the product and the economics that create the value. Givaudan sits exactly at that intersection; Temenos is a Swiss software company with the recurring revenue a private equity fund needs; Nike and On tests a strategic deal from the buyer's side.

Assumptions are sourced, judgement calls are explained, and each model can be stress tested live.

How it is built

Static HTML and JavaScript on GitHub Pages, with charts in Plotly. The valuation engines are plain JavaScript functions shared by the website, the Excel models and the decks, so every number ties out across formats.

Prices, earnings and option data are refreshed every weekday by an automated pipeline (Python, Yahoo Finance, GitHub Actions). The market figure at the top right shows the date of the last refresh.
